# 🥀 Дневник преподавателя и его студенточки

**Формат:** Telegram Mini App (Детерминированный интерактивный дневник-квест)  
**Стек:** React 19 (SPA) + Vite + Tailwind CSS + Telegram WebApp SDK + LocalStorage  
**Эстетика:** *Dark Academia* (Глубокий обсидиановый фон `#16161a`, винный бархат `#722f37`, винтажное сусальное золото `#d4af37`, типографика Cormorant Garamond и Cinzel).  
**Архитектура:** 100% клиентское приложение без ИИ и без бэкенда (детерминированное дерево диалогов на JSON-базе).

---

## 🏛️ Архитектура и механика работы

1. **Развертывание на GitHub Pages (HTTPS):**
   - Конфигурация Vite с `base: './'` гарантирует корректную загрузку ассетов из любого подкаталога репозитория.
   - Настроен автоматический GitHub Actions workflow (`.github/workflows/deploy.yml`).

2. **Telegram WebApp SDK Integration:**
   - Подключение SDK: `<script src="https://telegram.org/js/telegram-web-app.js"></script>`.
   - Инициализация: `window.Telegram.WebApp.ready()`, `expand()`, `enableClosingConfirmation()`.
   - Кастомизация темы Telegram: `setHeaderColor('#16161a')`, `setBackgroundColor('#16161a')`.
   - **Haptic Feedback:** тактильная виброотдача при выборе реплик и получении оценок (`notificationOccurred('success' / 'warning')`, `impactOccurred`).
   - **BackButton:** нативная кнопка Telegram «Назад» для возврата из кабинета в журнал.
   - Автоматическое определение имени дипломницы из `initDataUnsafe.user.first_name`.

3. **State Engine (Движок состояния):**
   - Все ветвления диалогов и характеристики модулей описаны в `src/data/scenario.json`.
   - Прогресс студентки (текущий этап, статус готовности, баллы зачета, штрафные отработки, разблокированные награды) синхронизируется с `window.localStorage`.
   - Встроенный Web Audio синтезатор для винтажных звуков (скрип пера, сургучная печать, звон колокольчика) без сторонних тяжелых аудиофайлов.

## 📖 Экраны приложения (UI)

### ЭКРАН 1: «ЖУРНАЛ ПОДГОТОВКИ»
- Список учебных модулей студентки:
  - **Модуль I:** Введение в теорию подчинения (Аудитория 305).
  - **Модуль II:** Анализ первоисточников тет-а-тет (Аудитория 402 в сумерках).
  - **Модуль III:** Дискуссия о личных границах (Малая профессорская библиотека).
  - **Модуль IV:** Предзащита диплома за закрытыми шторами (Главный кабинет зав. кафедрой).
  - **Модуль V:** Финальная аттестация и Высшая награда (У камина в полночь).
- Индикатор пайплайна сдачи материала:  
  `[ ⏳ Не начато ]` ➔ `[ 📖 Учит тему ]` ➔ `[ ✍️ Готова к докладу ]` ➔ `[ 🔒 Сдано на кафедре ]`.
- Кнопка студентки: **«✍️ Доложить о готовности материала»** — открывает закрытый диалог с Профессором.
- Просмотр теоретического конспекта кафедры перед сдачей.

### ЭКРАН 2: «КАБИНЕТ НАУЧРУКА»
- **Карточка настроения Профессора:**
  - *«Строгий цензор»* (Холодный взгляд, требование точности)
  - *«Снисходительный ценитель»* (Ироничный интерес, эстетика)
  - *«Опасное сокращение дистанции»* (Интимное приближение, стирание границ)
  - *«Взыскательный ментор»* (Дисциплинарная проверка на прочность)
- Реплика Преподавателя с чувственным подтекстом и контекстной подсказкой действия (*[Профессор медленно снимает очки...]*).
- Блок выбора ответа студентки (Прилежный, Кокетливый/Дерзкий, Покорный, Академический вызов).
- Визуальный и тактильный отклик начисления баллов (`+5`, `+10`, `+15` баллов) и отработок.
- Итоговая ведомость с сургучной печатью «СДАНО» и золотым салютом конфетти.

### ЭКРАН 3: «ЗАЧЕТНАЯ КНИЖКА»
- Официальный академический табель студентки № 7024/А:
  - Балл за прилежание (0 — 100) с анимированным золотым прогресс-баром.
  - Количество назначенных индивидуальных отработок (штрафные закрытые сессии).
  - Академический статус:
    - *«Отчислена на ковер к профессору»* (< 30 баллов)
    - *«Условно допущена к закрытой аттестации»* (30–59 баллов)
    - *«Прилежная аспирантка с особыми привилегиями»* (60–89 баллов)
    - *«Любимая дипломница с отличием»* (90–100 баллов)
  - Сводная ведомость с оценками по каждому модулю.
- **Секретный раздел «Условия закрытия сессии» (Пикантные награды):**
  - ☕ **20 баллов:** «Право на кофе-брейк без цензуры»
  - 🔑 **40 баллов:** «Индивидуальная консультация без посторонних глаз»
  - 🛡️ **60 баллов:** «Амнистия: Списание одной строгой отработки»
  - 🍷 **80 баллов:** «Вечерний разбор диссертации с бокалом вина»
  - 👑 **100 баллов:** «Полная капитуляция научного руководителя» (автомат и любое сокровенное желание).

### ЭКРАН 4: «ДОСЬЕ И НАСТРОЙКИ»
- Персонализация имени дипломницы.
- Переключатели звуковых эффектов и тактильной вибрации (Haptic Feedback).
- Кнопка безопасного сброса прогресса с подтверждением.

## 🚀 Быстрый старт и запуск

### 1. Установка и локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка готового бандла для продакшена
npm run build
```

После сборки папка `dist/` содержит полностью автономный статичный бандл.

## 📱 Подключение в Telegram Mini App

1. Опубликуйте проект на **GitHub Pages** (включите GitHub Actions в настройках репозитория: `Settings -> Pages -> Build and deployment -> Source: GitHub Actions`).
2. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
3. Отправьте команду `/newapp`.
4. Выберите вашего бота, укажите название приложения (например, `Дневник дипломницы`).
5. Укажите описание и загрузите аватар.
6. Введите полученный URL GitHub Pages (например, `https://<username>.github.io/<repo>/`).
7. Готово! Теперь Mini App можно открывать напрямую в диалогах через кнопку меню или inline-ссылку.
