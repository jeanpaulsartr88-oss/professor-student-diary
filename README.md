# 🥀 Дневник преподавателя и его студенточки

**Формат:** Telegram Mini App (Детерминированный интерактивный дневник-квест)  
**Стек:** React 19 (SPA) + Vite + Tailwind CSS + Telegram WebApp SDK + LocalStorage  
**Эстетика:** *Dark Academia* (Глубокий обсидиановый фон `#16161a`, винный бархат `#722f37`, винтажное сусальное золото `#d4af37`, типографика Cormorant Garamond и Cinzel).  
**Архитектура:** 100% клиентское приложение без ИИ и без бэкенда (детерминированное дерево диалогов на JSON-базе, настоящая система регистрации и два разных режима взаимодействия).

## 🎭 Различия в геймплее для Студентки и Преподавателя

### 1. Режим СТУДЕНТКИ:
- **Журнал подготовки:** просмотр этапов сдачи материала, чтение закрытых конспектов кафедры, кнопка *«✍️ Доложить о готовности материала»*.
- **Кабинет научрука:** сдача темы тет-а-тет, реакция на вопросы профессора, выбор вариантов ответов (*Прилежный / Кокетливый / Покорный / Академический вызов*), повышение баллов прилежания или получение строгих отработок.
- **Зачетная книжка:** табель оценок № 7024/А, рейтинг успеваемости, тайный раздел наград и кнопка *«Востребовать привилегию»*.

### 2. Режим ПРЕПОДАВАТЕЛЯ:
- **Кафедральная ведомость:**
  - Полный надзор за дипломницей (баллы, отработки, академический статус).
  - Административные рычаги: кнопки *«+ Наказать (отработка)»*, *«- Простить»*, *«+5 баллов за усердие»*, *«-5 баллов»*.
  - Кнопка *«🏛️ Вызвать студентку на опрос в кабинет №305»*.
  - Личный закрытый дневник профессора для заметок о студентке.
- **Кабинет экзаменатора:**
  - Профессор управляет ходом допроса дипломницы!
  - Переключение настроения в реальном времени: *«Строгий цензор»*, *«Снисходительный ценитель»*, *«Опасное сокращение дистанции»*, *«Взыскательный ментор»*.
  - Выбор вопросов и вариантов реакции студентки, фиксация смущения и проверка дисциплины.
  - Наложение официальной резолюции в ведомость с печатью *«ПОДПИСАНО»*.
- **Реестр закрытых соглашений:**
  - Профессор лично утверждает востребованные студенткой пикантные награды гербовой подписью (*«УТВЕРЖДЕНО НАУЧРУКОМ»*).

## 📱 Быстрое переключение ролей

В шапке приложения доступна кнопка со стрелками **⇄**, позволяющая в 1 клик переключиться между взглядом Профессора и взглядом Студентки для комфортного тестирования всех сценариев.
